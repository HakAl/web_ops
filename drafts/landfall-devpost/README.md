7. `readme-information-architecture.md`: recommended README hierarchy plus reproducible local and cloud instruction copy.
8. `social-post.md`: optional social copy with the required hashtag.
9. `claims-risk-table.md`: unresolved, prohibited, and cut-on-finalization claims.
10. `visual-system.md`: visual tokens and application guidance for the diagram, video, and Devpost gallery.
